## Make Commands

- `make` - Build and run
- `make zip` - Zip `cpp` and `h` files, keeping project structure
- `make flat-zip` - Zip `cpp` and `h` files, put all in root of zip, and flatten imports
- `make clean` - Remove build and zip files & directories

## Running

Run the program with `make` in terminal.
Make sure the variable `testing` in `main.cpp` is set to `false` to actually play the game.
